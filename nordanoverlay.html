Telemetry Overlay

A high-performance, real-time Heads-Up Display (HUD) engineered for Euro Truck Simulator 2 and American Truck Simulator, built to deliver zero-latency physics data directly to the driver's screen.

Project Overview

Built the pro way for our Virtual Trucking Company drivers, this application intercepts live physics and telemetry data directly from the game engine’s memory and renders it over the game window. It features a dual-window architecture: an invisible, borderless, click-through HUD that overlays the simulator, and an interactive "Command Center" for real-time visual customization.

To ensure a completely seamless user experience, I engineered a stealth auto-hide mechanism. The application actively monitors game time loops. Meaning the overlay part shows exactly when you are in the truck driving, and instantly vanishes the moment the game is paused or closed, keeping the desktop entirely clutter-free.

Core Technologies

Rust Tauri v2 Vue.js 3 C++ SDK CSS3 / HTML5

Key Features & Engineering

Direct Memory Access

Engineered a low-level Rust loop utilizing the Win32 API to read raw memory addresses from the Local\SCSTelemetry mapped file. Extracts raw byte data (speed, RPM, damage arrays) with absolute zero latency, dynamically converting m/s to precise KM/H and MPH readouts.

Time-Freeze Detection

Implemented a robust algorithmic check in Rust that strictly monitors the game engine's internal clock. If the clock stops updating, the system immediately recognizes a paused or minimized state, triggering the overlay to automatically vanish.

Transparent & Borderless Windowing

Manipulated OS-level window flags via Tauri's capabilities to forge a floating, shadowless, edge-to-edge transparent canvas. It seamlessly overlays the DirectX game window without capturing rogue mouse clicks, maintaining native gameplay flow.

Dynamic UI Logic & Persistence

Designed a hypercar-inspired Vue 3 frontend featuring segmented fuel-range visualizers and a dynamic shift-light cluster calculating percentage-based RPM thresholds. A seamless LocalStorage system instantly caches user preferences, custom X/Y coordinates, and theme arrays directly to disk.
